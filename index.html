This page verifies the integrity of your Git repository snapshot. The badge above indicates that your current state matches the expected snapshot configuration.

A Git snapshot badge is a verification mechanism that ensures your repository's state—including commits, branches, and configuration—matches a known good state at a specific point in time.

What's checked

  • Repository commit history integrity
  • Branch configuration and state
  • File structure and content
  • Metadata and timestamps

How it works

The snapshot badge uses cryptographic hashing to create a unique fingerprint of your repository state. When you run a check, the current state is hashed and compared against the stored snapshot. If they match, the badge displays as valid.

Use git snapshot check to verify your repository at any time.
