# 🍵 Tea Themed Matching Card Game

A fun and interactive matching card game with a cozy tea theme!

## Features

- **16 Tea-Themed Cards** - Match pairs of tea-related emojis including:
  - 🍵 Green Tea
  - ☕ Black Tea
  - 🫖 Teapot
  - 🍯 Honey Pot
  - 🌿 Mint
  - 🍋 Lemon
  - 🥛 Milk
  - 🍪 Biscuits

- **Game Statistics**
  - Track your moves
  - Count successful matches
  - Timer to measure your speed

- **Interactive Features**
  - Smooth card flip animations
  - Hint button (one per game)
  - New Game button to restart anytime
  - Win modal with final statistics

- **Responsive Design**
  - Works on desktop, tablet, and mobile devices
  - Beautiful tea-themed color scheme
  - Smooth animations and transitions

## How to Play

1. Click on cards to flip them and reveal the tea-themed emoji
2. Try to find matching pairs
3. Match all 8 pairs to win the game
4. Use the Hint button once per game to reveal a random card
5. Try to complete the game with the fewest moves and fastest time

## Game Rules

- Click on two cards to flip them
- If they match, they stay flipped and you get a point
- If they don't match, they flip back over
- The game ends when all pairs are matched
- You can use one hint per game to reveal a card for 1.5 seconds

## Running the Game

### Option 1: Open directly in browser
Simply open `index.html` in your web browser.

### Option 2: Use a local server
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
